# Retired Cloudflare protected-demo prototype

This guide is historical and is not an operational deployment path. The current
backend has no `protected-demo` mode or shared-password gate. The old launcher
fails closed and must not be changed to anonymously expose the local server.

Use [DEPLOYMENT.md](DEPLOYMENT.md) for the current Render synthetic demo and
localhost alternatives. A future protected tunnel requires a separately tested
access-control implementation and approval before public exposure.
